Erratum

Erratum to the table: the unit price of KX-7223 is 303 euros, not 253 euros.

Decisions made this week. The team decided to keep the old colour scheme for the first version and to postpone the dark mode to a later release. It also decided to use the existing hosting service, which saves about 45 days of work. The decisions were taken by consensus, and nobody asked for a vote. They are recorded in the decision log under RF-457.

Dependencies. The project depends on two other teams. The first, led by Jonas Salazar, provides the data and has promised an update in a few days. The second provides the login service, which has been stable for 45 weeks. If either of them changes its plan, we will tell the steering group at once, because a delay could affect the date of the first release.

Communication. The weekly status is sent to the steering group every Friday. The team keeps a public board where everybody can see what is in progress. If something blocks the work for more than a day, it is raised in the daily check-in and, if needed, with the steering group. Next month we will hold a short review to see how the project is going overall.
