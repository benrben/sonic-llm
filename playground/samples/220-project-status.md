Project Orchard: weekly status

Week ending February 24, 2027. Written by Ilse Novak, project manager, for the steering group.

Overall
The project is on track but needs attention in one area. 8 people worked on it this week. The team finished the planned work on the first screen and started on the second one. The mood in the team is good, and the daily check-in is working well.

Money
So far 53000 euros of the total budget of 262000 euros have been spent. This is in line with the plan for this point in time. No extra spending has been approved. The finance team will send the next report at the end of the month.

Milestones
The next milestone, the first version for real users, is due on March 22, 2027. The team believes this is still realistic. The milestone after it is not yet scheduled, and will be discussed once the first version is in the hands of users.

Quality
85 bugs have been closed since the project began. 10 bugs are still open, and none of them stops people from using the product. The most serious open bugs are a layout problem on small screens and a slow search. Sven Salazar is working on both and expects to finish them next week.

Risks and blockers
One blocker is open: we are waiting for the supplier contract. Nadia Petrov is the owner of this blocker and has been chasing it for several days. If it is not solved soon, the milestone may move by a week or two. The steering group is asked to help by making a quick decision when the answer arrives.

Communication. The weekly status is sent to the steering group every Friday. The team keeps a public board where everybody can see what is in progress. If something blocks the work for more than a day, it is raised in the daily check-in and, if needed, with the steering group. Next month we will hold a short review to see how the project is going overall.

Dependencies. The project depends on two other teams. The first, led by Tilda Wexler, provides the data and has promised an update in a few days. The second provides the login service, which has been stable for 17 weeks. If either of them changes its plan, we will tell the steering group at once, because a delay could affect the date of the first release.

Team notes. A new colleague, Tilda Wexler, joined the team on Monday and is already settling in. The team will move to a larger room next month. A short workshop on testing was held on Wednesday and 17 people attended. The team agreed to keep the daily check-in to fifteen minutes and to write down the decisions in the shared notes.

Decisions made this week. The team decided to keep the old colour scheme for the first version and to postpone the dark mode to a later release. It also decided to use the existing hosting service, which saves about 17 days of work. The decisions were taken by consensus, and nobody asked for a vote. They are recorded in the decision log under RF-927.

Next week
Finish the second screen, fix the layout bug, write the user guide and run a first test with three friendly users. Ilse Novak will send a short note on Friday to say how it went.
